# 四屏看盘

[打开在线看盘页](https://aaron20011020.github.io/four-screen-market/)

四屏看盘把同一份币安 USDT 永续合约的四个周期放在一个浏览器窗口里。你可以用 4 小时图观察趋势，用 1 小时图寻找支撑和压力，再对照 15 分钟和 5 分钟图观察价格在关键位置的反应。四张图共享合约选择，省去反复切换标签页和核对交易对的操作。

## 看盘功能

| 功能 | 用法 |
| --- | --- |
| 四周期对照 | 默认显示 5 分钟、15 分钟、1 小时和 4 小时。每格可独立选择从 1 分钟到 1 天的预设周期。 |
| 统一切换合约 | 在左上角选择 BTC、ETH、XAU、XAG、SOL、BNB、XRP 或 DOGE 的 USDT 永续合约，图表、报价和盘口随之切换。 |
| 局部放大 | 点任一格的放大按钮，左侧保留四张小图，右侧单独显示所选周期的大图。点「返回四屏」恢复。大图独立加载，手动画线与指标设置可能需要重新配置。 |
| 图表指标 | 通过每张 TradingView 图表的原生工具栏添加均线、唐奇安通道等指标。点「独立打开」可以单独查看该合约。 |
| 顶部行情 | 展示最新成交价、24 小时涨跌额与涨跌幅、标记价、指数价、最高价、最低价及成交量。最新价平滑过渡，相比上一条报价上涨显示红色，下跌显示绿色。 |
| 实时盘口 | 点「盘口」展开或收起左侧 Order Book。卖盘为红色，买盘为绿色，最多各显示 20 档。每档列出价格、挂单数量和折合 USDT 的金额，中间显示最优买卖价差。 |
| 本地偏好 | 浏览器记住所选合约、各格周期和盘口开关，下次打开可继续使用。 |

## 数据与运行方式

项目是一个独立的静态 HTML 页面，通过 GitHub Pages 发布。K 线由 TradingView 展示，顶部行情和盘口通过币安合约公开 WebSocket 更新。盘口只在展开时订阅，关闭时断开。访问者可以直接看盘，无需交易账户或 API 密钥。

本地使用时，下载仓库根目录的 `index.html`，用浏览器打开即可。图表和行情需要联网；不同数据源的更新时间可能略有差异。
